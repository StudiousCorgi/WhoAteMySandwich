Who Ate My Sandwich - FINAL VERSION

This project demonstrates core JavaScript concepts:
- Arrays, Objects, Variables, Constants
- Functions: defined and called correctly
- Loops: for, forEach, and while
- Conditional Logic: if, else, switch
- DOM Manipulation: element selection, creation, and updates
- Event Handling: addEventListener, removeEventListener
- Game Algorithm: Random guilty suspect, question logic, win/lose handling

To run:
1. Place all suspect PNGs (matt.png, mike.png, sarah.png, alicia.png, chase.png) in /images
2. Place BreakRoom.jpg in /images
3. Open index.html in your browser
